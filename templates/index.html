How TifLAS Converts Image Logs into LAS

TifLAS processes each log through a structured workflow designed to improve extraction quality and produce usable LAS output.

1. Image Preparation

De-skewing, contrast correction, and grid or layout cleanup to prepare the log for extraction.

2. Depth Scale Reconstruction

Rebuild depth reference from markers, ticks, and grid structure.

3. Curve Identification

Locate and isolate plotted log curves using computer vision techniques.

4. Curve Digitization

Translate extracted curves into numerical depth-value data.

5. LAS Export

Structure extracted data into standard LAS files for downstream use.
